How the competition works (read this first)
1

Train

Build a reinforcement-learning agent (PPO, SAC, …). It sets every business lever of one retailer each round.

2

Self-check

Play it for 1,000 rounds against four scripted rivals. This page replays exactly that kind of match.

3

Submit

One checkpoint .zip + entry.json per team, filed as a GitHub issue before the deadline.

4

Tournament

The organizer plays all entries against each other (no scripted rivals), rotating seats. Highest total profit wins.

The world

25 regions. Region 0 (Smolyan) is stranded — hatched, nobody can enter. Regions 1–24 cycle METRO (biggest demand), AFFLUENT, LOYAL, FRONTIER (smallest).

The players

2–6 seats, each starting with one store in its home METRO region (ringed on the map) and equal cash. Each round a seat sets price, marketing, assortment, promotion, service, loyalty, wages… and may buy a store in a new region for a one-time __PRICE__.

The goal

Score = cumulative profit, after wage and warehouse penalties. More stores ≠ better: each store adds running cost and overhead, and cash can't go far below zero.
